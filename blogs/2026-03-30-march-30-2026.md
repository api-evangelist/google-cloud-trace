Change For any new project that is created on or after March 30, 2026, if the project enables the Cloud Trace API, then Google Cloud Observability also enables the Telemetry API . Feature You can use the Cloud Trace API MCP server to let agents and AI applications interact with your trace data. This feature is in Preview .
